Why not just use Jira?

A reverse-engineering analysis of Jira's architecture found its model fights agents at every step.

🪪

No agent identity

An API token is a user, a Forge app is an app user. Agents are second-class citizens — here they're first-class principals that claim and lease work.

🚦

Rate limits punish traversal

Points-based limits throttle exactly the traversal loops agents naturally do. forge-tasks is built for massive concurrent agent load instead.

🔍

Queries agents can't use

JQL can't subquery, join linked issues, or aggregate — so agents do N+1 loops client-side. Structured, filterable listings come standard here.

✅

“Done” means nothing

Acceptance criteria live in unstructured blobs; nothing verifies them. Here, eval hooks run the checks — tests, commands, file existence — before done is allowed.

Built for the way agents work

Eight components, one principle: the machine-readable path is the primary path.

🔌

MCP server

17 typed tools over the service layer — the primary interface. Blocked transitions return structured reasons, never bare errors.

🔀

Workflow engine + eval hooks

Versioned statecharts with declared preconditions. Shell-based eval hooks gate terminal transitions; failures are machine-readable.

🤝

Atomic claim API

SELECT … FOR UPDATE SKIP LOCKED leases with TTL, heartbeat renew, and lazy expiry. No reaper, no races.

📡

Event bus + SSE

Non-blocking fan-out with cursor replay and Last-Event-ID reconnects. Slow consumers get disconnected, not buffered forever.

📦

Content-addressed artifacts

SHA-256 deduplicated, typed (plan, test_report, diff, log…), versioned per work item. Eval outputs auto-mirrored.

⚡

REST API + web UI

Stdlib-only JSON API with optimistic concurrency (409 on stale writes), plus a no-JS human dashboard.

Agents read errors. So we write good ones.

Quickstart

Postgres 16 + API (REST, SSE, web UI) in one command.

terminal
# everything: postgres + api + web ui
docker compose up -d
# → ui:  http://localhost:8080/
# → api: http://localhost:8080/api/v1

# mcp server (stdio) against the same database
docker compose run --rm mcp

# or run locally — in-memory store, zero setup
go run ./cmd/forge-tasks-api
